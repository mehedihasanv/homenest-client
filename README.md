# HomeNest - A Real Estate Listing Portal

Welcome to **HomeNest**, a modern real estate listing platform where property owners can post rental or sale listings, and users can browse, search, and filter properties by location, price, or category.

🔗 **Live Site:** [https://magical-sable-9a6a36.netlify.app/]



## ✨ Features

- 🔐 **Authentication System**  
  Email/password and Google login with protected routes for adding, updating, and viewing personal properties.

- 🏠 **Property CRUD Operations**  
  Users can add, update, delete, and view their own properties. All properties are stored in MongoDB.

- 📊 **Ratings & Reviews**  
  Logged-in users can rate and review properties. My Ratings page shows all reviews submitted by the user.

- 🔍 **Search & Sort Functionality**  
  All Properties page includes search by property name and sort by price or posted date (sorted from backend).

- 📱 **Responsive Design**  
  Fully responsive layout for mobile, tablet, and desktop views with consistent styling and spacing.
